# Functional JavaScript's Utility Library

This is a JavaScript utility library based on functional programming paradigms.  
It provides a set of utilities for common functional programming challenges and demonstrates core functional concepts, including:

- Partial Application
- Currying
- Folding (Linear Fold)
- Unfolding (Linear Unfold)
- Functional Map and Filter
- Lazy Evaluation
- Memoization

Node version used v25.2.1
npm version used 11.6.2

- TypeScript for type safety
- ESLint + Prettier for code quality and formatting
- Vitest for testing
- Husky for pre-commit and pre-push hooks
